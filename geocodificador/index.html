Herramienta GIS · módulo en desarrollo

Direcciones a coordenadas

La herramienta desarrollada admite CSV o Excel con direcciones en una columna, o con calle y número separados. Registra coordenadas generadas. Solo para direcciones no localizadas, acepta un campo opcional COORD_GOOGLE con latitud, longitud aportadas por el usuario; lo utiliza para construir la geometría del punto, siempre dentro de Santiago.

  • Validaciones de calle, numeración, paridad, distancia y límite de Santiago según capas disponibles.
  • Clasificación: exacta, interpolada, aproximada o no localizada.
  • El campo COORD_GOOGLE no sobrescribe puntos geocodificados inicialmente; se conserva la fuente y se valida la ubicación dentro del límite comunal.
  • Barrios y territorios solo cuando están cargadas sus coberturas oficiales.
  • Descarga SIG en ZIP con GeoPackage mediante el motor Python.

Estado de publicación: esta página es el acceso institucional al módulo. El motor de geocodificación y exportación GPKG requiere ejecutar la aplicación Python; GitHub Pages no puede ejecutar ese servidor. Todavía no hay un servicio de procesamiento alojado en línea.

Implementación

Para operar desde GIS STGO en línea se deberá alojar el backend Python con las capas de ejes numerados, límite comunal, barrios y territorios y conectar esta pantalla al servicio. Mientras tanto se mantiene como módulo de desarrollo sin simular resultados de geocodificación.
